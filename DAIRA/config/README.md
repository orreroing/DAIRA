* Default DAIRA run config: `DAIRA_DEFAULT.yaml`
* Language-specific validation configs: `DAIRA_C_CPP.yaml`, `DAIRA_JAVA.yaml`, and `DAIRA_RUBY.yaml`
* Multilingual SWE-bench subsets for validation: `multilingual_subsets/` and `multilingual_subsets_all/`
* Upstream-compatible configs are retained when they are needed by the DAIRA runtime.

DAIRA is built on SWE-agent, so the upstream SWE-agent configuration documentation is still useful for inherited options:
https://swe-agent.com/latest/config/config
